# Clothing by Saurina — Android

[Descargar la última versión](https://github.com/pepe631983/saurina-clothing-descargas/releases/latest)

Instale el archivo APK sobre la aplicación existente, sin desinstalar ni borrar datos. Desde 1.1.28, las próximas versiones se anuncian dentro de la app con el botón **Actualizar**. Android puede pedir confirmar la instalación.

Este repositorio contiene instaladores y el manifiesto de actualizaciones, sin datos de clientes ni el proyecto fuente.

Para publicar: subir primero la APK firmada a Releases, verificar la descarga y luego cambiar `actualizacion.json`. No anunciar versiones que aún no estén disponibles. Publicar `{}` en ese archivo pausa los avisos, sin desinstalar ni degradar versiones.
